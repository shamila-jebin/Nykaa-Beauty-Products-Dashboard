# 💄 Nykaa Beauty Products Dashboard

## 📌 Project Overview

This project presents a Nykaa Beauty Products Dashboard designed to analyze beauty product data, compare brand performance, explore pricing patterns, and understand revenue trends through interactive visualizations.

The dashboard provides a visual overview of brand-wise revenue, product-level analysis, brand pricing, category-wise price distribution, and revenue over time.

## 🎯 Project Objectives

- Analyze revenue across different beauty brands.
- Compare product prices across brands.
- Explore product-level performance and quality indicators.
- Understand category-wise price distribution.
- Analyze revenue trends over time.
- Use interactive filters to explore product data.

## 📊 Key Dashboard Features

- **Brand by Revenue:** Compare revenue across brands.
- **Quality by Product Name:** Explore product-level quality indicators.
- **Brand by Price:** Compare brand-wise pricing.
- **Category by Price:** Understand price distribution across categories.
- **Date by Revenue:** Explore revenue trends over time.
- **Interactive Filters:** Filter data by brand, month, and reviews.
